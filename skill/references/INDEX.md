# Reuse Catalogue

Use the catalogue only after a task exposes a reuse or design trigger. It is advisory, not
a compulsory implementation library.

- Entries: `skill/registry/reuse-catalogue.json`
- Workflows: `skill/registry/workflows.json`
- Search: `getdone-search`
- Lifecycle procedure: `skill/workflows/governance/skill-authoring-lifecycle.md`
- Organisation-overlay example: `skill/references/examples/organisation-catalogue-overlay/`

Each entry states when to use and avoid it, applicable languages, related entries, and its
canonical product path. Adoption still requires task-specific evidence.

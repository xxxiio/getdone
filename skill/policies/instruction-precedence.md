# Instruction Precedence

## Applies when
Two or more instructions affect the same decision or cannot all be satisfied.

## Required action
1. Apply safety, legal, security, and platform constraints.
2. Follow the explicit current human instruction.
3. Apply consuming-project rules, the task specification, and active project state.
4. Apply the selected workflow, project conventions, affected language standards, core standard,
   then templates and examples.
5. When a material conflict remains, stop the conflicting action and record which
   instruction prevailed and why.

## Required evidence
Record the conflicting instructions, precedence decision, resulting scope change, and
residual risk in the task journal or completion report.

## Exceptions
No lower-precedence instruction may silently override a higher-precedence instruction.

# Architecture-Change Acceptance

## Objective
Introduce or change a durable boundary through explicit options and trade-offs.

## Pass conditions
An ADR records context, alternatives, decision, compatibility, rollout, reversal, ownership, and validation of the smallest viable slice.

## Required evidence
Record the task-specific proof above together with the core gate statuses and commands.

## Waiver conditions
Use the core waiver format; name the unavailable primary evidence, alternative evidence, and residual risk.

## Failure conditions
A diagram-only decision, speculative abstraction, or irreversible migration without staged evidence.

# Feature Acceptance

## Objective
Demonstrate the smallest useful user-visible or API-visible slice.

## Pass conditions
A test at a stable observable boundary fails before implementation and passes afterward; usage and compatibility effects are documented.

## Required evidence
Record the task-specific proof above together with the core gate statuses and commands.

## Waiver conditions
Use the core waiver format; name the unavailable primary evidence, alternative evidence, and residual risk.

## Failure conditions
Scaffolding without usable behaviour, hidden configuration requirements, or missing public examples.

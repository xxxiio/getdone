# Migration: 0.4.0 to 0.5.0

Version 0.5.0 does not change the `minimal` or `standard` bootstrap template bodies or profile versions. Existing project-owned `.agent/` state requires no template migration.

Projects may optionally:

1. Install a thin agent-specific adapter with `getdone-install-adapter`.
2. Run `getdone-validate-project` against the selected shared checkout.
3. Record the pinned shared tag or commit in their dependency records.

Existing agent-specific instruction files remain project-owned and are not overwritten unless an explicit overwrite is authorised.

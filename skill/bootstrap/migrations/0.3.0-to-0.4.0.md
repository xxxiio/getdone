# Migration: 0.3.0 to 0.4.0

## Scope

Version 0.4.0 adds read-only section-aware comparisons for modified managed Markdown files. It does not change bootstrap profile contents or require project-local file replacement.

## Safe automated actions

No project migration action is required. Existing projects may immediately use:

```bash
getdone-check-updates --project-root /path/to/project --sections
```

JSON consumers should tolerate the new `merge_suggestion` field on each update result.

## Manual review

Modified Markdown files may now report additions, removals, heading changes, content changes, and reordering. These are review aids only and must not be interpreted as an automatic merge plan.

## Validation

- Confirm `--sections` does not change project files.
- Confirm modified files remain ineligible for `--apply-replacements`.
- Validate JSON consumers against `schemas/section-merge-suggestion.schema.json` when they depend on the new field.

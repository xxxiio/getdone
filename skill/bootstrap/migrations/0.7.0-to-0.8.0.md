# Bootstrap Migration: 0.7.0 to 0.8.0

- Profile bundle versions advance from 1.2.0 to 1.3.0.
- Bootstrap creates `.agent/skills.lock.json` programmatically.
- Project instructions verify the lock before loading shared guidance.
- Existing project-owned Markdown remains untouched unless separately migrated.

Create the lock after reviewing the new shared checkout:

```bash
getdone-lock \
  --project-root /path/to/project \
  --skills-root /path/to/getdone \
  --write
```

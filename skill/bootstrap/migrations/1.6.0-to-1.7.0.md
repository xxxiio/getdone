# Standard profile 1.6.0 to 1.7.0

The standard profile adds two repeatable, project-owned planning templates:

- `.agent/plans/PROJECT-PLAN-TEMPLATE.md`
- `.agent/plans/EXECUTION-PLAN-TEMPLATE.md`

Existing project records are not rewritten. Apply the standard profile update to add the templates, then create plan instances only when project or execution planning is needed.

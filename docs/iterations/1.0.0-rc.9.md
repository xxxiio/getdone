# Iteration 1.0.0-rc.9: Conversational Planning

## Why this work was next

GetDone already governed implementation, evidence, and release work, but users could not begin with a whole-project discussion or convert an approved milestone into validated slices. Planning was therefore the highest-value unfinished workflow before broader public testing.

## Delivered

- Project-planning and execution-planning workflows.
- Planning acceptance gates and deterministic context routing.
- Controlled project-plan and execution-plan templates.
- Execution-plan slice dependency and cycle validation.
- Standard profile 1.7.0 and a non-destructive profile migration note.
- ChatGPT discovery/commitment guidance and file-output protocol.
- `getdone planning-prompt` for project and execution modes.
- Zensical planning documentation and generated workflow catalogue pages.

## Scope boundary

The workflows support discussion and approved record generation. They do not autonomously invent product requirements, approve tentative decisions, or silently claim that generated files were applied.

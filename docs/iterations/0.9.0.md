# Iteration 0.9.0: Measured Context Selection

## Why this was the next step

The project-local composition lock made guidance reproducible, but agents still had to decide
which canonical files to load for each task. The final capability milestone had to demonstrate a
measurable token-to-coverage improvement before adding another public tool.

## Delivered

- A deterministic selector for feature, bug-fix, refactoring, and investigation tasks.
- Language-aware task manifests across Python, q/kdb+, C++, Rust, and Dart/Flutter.
- Workflow-parent and declared-reference resolution.
- Core, change-type, and language acceptance-gate selection.
- Conditional policy and catalogue triggers without eager document loading.
- A JSON Schema, direct-script interface, and installed console command.
- Eight representative benchmark fixtures and a committed drift-checked result.
- A fixed v1.0 rollout plan and explicit pre-v1 stop rule.

## Evidence

The benchmark uses a 19,291-token approximate baseline containing 82 core-guidance documents.
The selected sets contain 16 or 17 documents and approximately 4,788 to 4,915 tokens.

- Workflow-routing accuracy: 100%.
- Required-document recall: 100%.
- Missed acceptance gates: 0.
- Average token reduction: 74.84%.
- Minimum token reduction: 74.52%.

The approximation uses four characters per token. These are static context-selection results, not
claims about coding or design quality.

## Scope control

- No natural-language task classifier was added.
- No prompt generator or document concatenator was added.
- Startup documents are not repeated in every task manifest.
- Unsupported task classes continue to use the workflow router.
- Real coding outcomes remain a release-readiness dogfood requirement.

## Next deterministic step

Begin Milestone 11 and produce `v1.0.0-rc.1`: dogfood representative repositories, freeze public
contracts, establish the supported CI matrix, and fix rollout blockers only.

## Validation

- 103 tests passed.
- Repository, front-matter, registry-index, release-metadata, compilation, and whitespace checks passed.
- The committed benchmark result matches the current repository content.
- Direct-script, editable-install, and built-wheel selector smoke tests passed.
- Changed Python code has no lines over 100 columns and no functions over the 50-line review trigger.

but it must not become another open-ended feature phase.

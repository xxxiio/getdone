# Iteration 1.0.0-rc.6: GetDone Product Rename

## Outcome

Rename the product, repository identity, Python distribution, implementation package,
commands, documentation site, generated artefacts, schemas, adapters, and examples to
**GetDone** before the first public compatibility boundary.

## Delivered

- Canonical product and repository name: `GetDone` / `getdone`.
- Canonical Python distribution and module: `getdone-tools` / `getdone`.
- Canonical `getdone-*` command family.
- Renamed Cursor adapter, schema identifiers, documentation navigation, generated pages,
  shared-checkout examples, release archives, and release instructions.
- RC.5-to-RC.6 migration guidance.

## Compatibility

Bootstrap profile versions remain at `1.6.0`; no project-owned `.agent/` record is
rewritten. The public package exposes only the canonical `getdone` names.

## Evidence

- Full unit and contract suite passes.
- Repository, release, registry, documentation-drift, benchmark, and rollout checks pass.
- Wheel installation exposes the canonical command family.
